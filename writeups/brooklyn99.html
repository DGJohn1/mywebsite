TryHackMe Linux Steganography Easy

Enumeration

nmap -sV -T4 -A 10.10.142.255

From this we can see a few things:

  • FTP server with anonymous login
  • SSH
  • HTTP webserver

For now, let's see the website.

Looking further into the source code for this webpage, we're given a big hint.

There seems to be something hidden in an image, and the only image we currently have is the one on the main page.

Steganography

I quickly check the FTP server, only to find nothing useful. I download the image and start analyzing it.

Nothing suspicious there. I look online for steganography tools and land on stegcracker.

I run a password crack to see if I can break it using rockyou.txt.

Successfully cracking the password gives us login information for holt.

SSH

Time to SSH in.

We're in.

Privilege Escalation — Nano

User flag out of the way, let's see what privileges holt has via sudo.

Interesting — we can abuse a GTFOBins technique for nano to escalate privileges.
